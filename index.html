CSSP VISUAL LABS / ATU GALWAY

Authentication
under the surface.

A password proves identity at login. A session carries that identity into later requests. Follow both mechanisms, inspect the evidence, and test your predictions.

Cookie Theft

Follow one session ID from creation to capture, replay and revocation.

  • A browser logs in and the server issues a session cookie
  • Eligible requests carry the cookie back for lookup
  • An observer in the traffic path can copy an exposed ID
  • Test TLS, cookie policy, deletion and server invalidation

Password Check: Argon2id

Discover how a server checks a password using a stored verifier.

  • A fresh random salt, then a memory-hard hash
  • Only the verifier is stored
  • Login: derive again and compare
  • Explore salts, memory, passes, lanes and offline guesses
