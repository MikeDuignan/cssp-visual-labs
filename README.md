# CSSP Visual Labs

Two single-file, offline interactive pages for COMP09031 Cybersecurity and Secure Programming (ATU Galway). Open them in a browser; nothing to download or install.

- **Cookie Theft** (session hijacking, visually): [`cookie-theft/`](cookie-theft/)
- **Password Check, Argon2id** (how a server stores and checks a password): [`argon2id/`](argon2id/)

Live pages: <https://mikeduignan.github.io/cssp-visual-labs/>

Each lab folder has its own README with the steps, controls and a suggested teaching script. All sites, accounts and data in the pages are fictional, and the pages make no network requests. They are for teaching only.

These pages go with the Week 6 cookies and sessions videos (private repository `CSSP-Cookies`).
